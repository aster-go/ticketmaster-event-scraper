# Dockerfile Проверка

## Изменения для продакшена

### ✅ Обновлен базовый образ
- **Было:** `apify/actor-node-puppeteer-chrome:22-24.32.1` (с Puppeteer)
- **Стало:** `apify/actor-node:22` (без браузера, легче и быстрее)

### ✅ Убраны ненужные зависимости
- Удалены проверки `puppeteer` и `playwright`
- Удалена проверка `check-puppeteer-version.mjs` (файл не существует)
- Оставлена только проверка `apify` SDK

### ✅ Оптимизация
- Используется multi-stage build для уменьшения размера образа
- Добавлен `.dockerignore` для исключения ненужных файлов
- Правильная последовательность копирования файлов для кэширования слоев

## Структура Dockerfile

1. **Builder stage:**
   - Установка dev зависимостей
   - Компиляция TypeScript
   - Создание `dist/` директории

2. **Production stage:**
   - Установка только production зависимостей
   - Копирование скомпилированных файлов из builder
   - Минимальный размер образа
